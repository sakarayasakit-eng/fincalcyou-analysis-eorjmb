# fincalcyou — Growth Strategy (Cycle 1 research synthesis)
_Last updated: 2026-08-11_

## The core decision: calculators now, comparison later
The most valuable, defensible growth is **pure-math calculators that need no external data**
(debt payoff, credit-card payoff, DTI, balance transfer, compound interest, amortization,
refinance). They have very high, evergreen search demand, real user utility, zero data-freshness
risk, and they capture much of the same search intent as the comparison giants — without competing
on their terms.

## Why the credit-card / bank COMPARISON directories are gated (not built)
Research (WalletHub, NerdWallet, Bankrate, Forbes Advisor, CFPB) shows a comparison directory requires:
1. **Continuously verified product data** — issuers change APRs, fees and bonus offers constantly;
   incumbents employ editors and pull Fed G.19 / CFPB / issuer feeds. We cannot fabricate this and
   cannot autonomously keep it current. The brief itself says: if info can't be verified, do NOT publish.
2. **Affiliate relationships** — the only real monetization ($50–200/approved app), which requires the
   owner to sign up and, per CFPB (Feb 2024), manage ranking-bias disclosure. A business decision.
3. **Competing head-on with domain-authority incumbents** on their strongest, most defended turf.

**Decision:** do NOT stub a fake card/bank database. Build the calculators (which also rank for
card/loan intent), and only build the comparison directory once a verified data source + affiliate
program + disclosure workflow exist. Documented as GATED in opportunities.csv.

## Build order (this cycle and next)
1. [DONE] Fix CSP P0 (site-wide header).
2. [DONE] Flagship calculator: Debt Payoff (avalanche vs snowball), math verified.
3. [NEXT] Credit-card payoff, DTI, balance-transfer, compound-interest calculators (P0/P1, no data).
4. [NEXT] Cross-link the new "debt" cluster; add a debt hub.
5. [LATER] Refinance, amortization, CAGR, FIRE.
6. [GATED] Comparison directories — only with verified data + affiliate + compliance.

## Guardrails (from the brief, enforced)
- Never fabricate rates, fees, offers, authors, reviews, or expertise.
- Every new page must pass: unique value, data accuracy, real intent, differentiation, trust, clean monetization.
- Optimize USER VALUE x DEMAND x TRUST x DIFFERENTIATION — never page count.
